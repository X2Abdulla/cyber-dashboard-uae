# دِرْع | منصة الأمن السيبراني والإدارة الذكية

نظام مؤسساتي كامل بواجهة عربية (RTL) مبني بـ **Next.js 16 (App Router) + React 19 + PostgreSQL + Drizzle ORM + Tailwind CSS v4**، يغطي: مصادقة آمنة بأدوار صلاحيات، مصادقة ثنائية (TOTP)، تشفير AES-256، إدارة ملفات مع فحص أمني وتصنيف، فحص روابط مشبوهة، رصد تنبيهات حية، محرك ذكاء تحليلي (كشف شذوذ + مخاطر المستخدمين)، سجل عمليات غير قابل للتعديل، تنبيهات بريد/SMS، وتقارير دورية بتصدير PDF/Excel/CSV/JSON/TXT.

---

## 1) المزايا الرئيسية

| الوحدة | ما توفره |
|---|---|
| 🔐 مصادقة آمنة | تشفير `bcrypt` بعامل تكلفة 12، قفل الحساب بعد 5 محاولات (15 دقيقة)، حد معدل لكل IP وحساب، جلسات JWT (HS256) في كعكة `httpOnly + SameSite=Strict` تنتهي خلال 8 ساعات، تحقق من مصدر الطلب (CSRF)، ورسائل خطأ لا تكشف صحة اسم المستخدم + مقارنة وهمية لمعادلة زمن الاستجابة (منع هجمات التوقيت). |
| 👥 أدوار الصلاحيات | ثلاثة أدوار: **مدير النظام / مشرف أمني / مستخدم**، ومصفوفة صلاحيات دقيقة (18 صلاحية) في `src/lib/auth/rbac.ts` تُطبَّق في الخادم وتنعكس على الواجهة. |
| 🛡️ المصادقة الثنائية | TOTP (RFC 6238) متوافق مع Google/Microsoft Authenticator و Authy، السر مخزّن مشفراً بـ AES-256-GCM، تفعيل/تعطيل موثّق في سجل العمليات. |
| 📁 إدارة الملفات | رفع حتى 10 م.ب، فحص متعدد المراحل (امتداد → بايتات سحرية → قواعد توقيع وسلوك → إنتروبيا)، كشف EICAR وانتحال الامتداد، تصنيف تلقائي (مالي/شخصي/طبي/عقود/تقني/موارد بشرية/عام) ومستوى حساسية، عزل تلقائي للمشبوه، رفض تام للضار مع تنبيه حرج، بصمة SHA-256، وتنزيل آمن كـ `attachment` مع `nosniff`. |
| 🔗 فحص الروابط | محرك `DERAA-URLGuard` يحلل الرابط بنيوياً دون أي طلب خارجي: IP بدل النطاق، بيانات اعتماد مضمّنة، Punycode/Homograph، نطاقات عالية الخطورة، خدمات التقصير، محاكاة العلامات التجارية، والكلمات التصيّدّية (عربية وإنجليزية). |
| 🔎 تشفير البيانات | تشفير محتوى الملفات وكل الأسرار الحساسة بـ **AES-256-GCM** (مفتاح مشتق من `DATA_ENCRYPTION_KEY`)، مع بادئة سحرية `DRAA1` للتوافق الرجعي. |
| 📊 لوحة تحكم حية | رسوم SVG خالصة (مساحي حي، دائري، أعمدة، حلقة قياس، خطوط مصغرة)، بث تهديدات متحرك، تحديث تلقائي كل 6 ثوانٍ، وجرس تنبيهات يسحب الجديد كل 20 ثانية. |
| 🧠 الذكاء التحليلي | خط أساس إحصائي (Z-Score)، انحدار خطي للتنبؤ بتهديدات 24 ساعة، كشف شذوذ (ذروات دخول فاشل، مصادر هجوم متكررة، أصول شاذة)، تحليل سلوكي لكل مستخدم (UEBA)، ومحرك توصيات عربي بالإجراء المقترح. |
| 🧾 سجل عمليات محصّن | كل عملية (نجاح/فشل/حظر) مع المستخدم و IP ووكيل المستخدم و JSON إضافي، **سلسلة تجزئة SHA-256** + **Trigger في القاعدة يمنع UPDATE/DELETE**، وزر تحقق من سلامة السلسلة. |
| 📣 تنبيهات فورية | قنوات قابلة للتبديل: بريد عبر Resend، SMS عبر Twilio، وتنبيه داخلي — مع سجل تسليم كامل وحالات (sent/skipped/failed). التنبيهات الحرجة والعالية فقط تُبث خارجياً لتقليل ضجيج التنبيهات. |
| 📈 التقارير | تقارير يومية/أسبوعية/شهرية بمؤشرات مجمّعة وملخص تنفيذي عربي، تصدير **PDF (مستند مطبعي رسمي) / Excel (.xls) / CSV / JSON / TXT**، وكل تصدير يُسجَّل في سجل العمليات. |
| 📱 التصميم | متجاوب بالكامل (جوال/لوحي/حاسوب)، ثيم داكن بطابع SOC، درج جانبي منزلِق على الجوال، دعم `prefers-reduced-motion`، وأنماط طباعة مخصصة. |

## 2) متطلبات التشغيل

- **Node.js 20.9+** (المشروع مُختبر على Node 22)

## 3) خطوات التشغيل (خطوة بخطوة)

### الخطوة 1 — تثبيت الاعتماديات
```bash
npm install
```

### الخطوة 2 — إعداد متغيرات البيئة
أنشئ/عدّل ملف `.env` في جذر المشروع:

```env
# قاعدة البيانات (إلزامي)
DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/app_db

# سر توقيع الجلسات JWT (إلزامي في الإنتاج — 32 حرفاً عشوائياً على الأقل)
AUTH_SECRET=ضع_هنا_قيمة_عشوائية_طويلة

# مفتاح تشفير البيانات AES-256 (إلزامي في الإنتاج)
DATA_ENCRYPTION_KEY=ضع_هنا_مفتاحاً_عشوائياً_مختلفاً

# قنوات التنبيه الفوري (اختياري — بدونها تُسجَّل الرسائل كـ "غير مفعّل")
ALERT_EMAILS=soc@company.com,manager@company.com
ALERT_EMAIL_FROM=alerts@company.com
RESEND_API_KEY=re_xxxxxxxxxxxxxxxxxxxxxxxx
ALERT_PHONE_NUMBERS=+966500000000,+966511111111
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=xxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_FROM_NUMBER=+15551234567
```

> توليد قيم عشوائية آمنة:
> ```bash
> node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
> ```

### الخطوة 3 — تطبيق مخطط قاعدة البيانات
الطريقة الأولى (موصى بها):
```bash
npx drizzle-kit push
```

```bash
npm run dev
# ثم افتح: http://localhost:3000
```

### الخطوة 5 — بناء وإطلاق الإنتاج
```bash
npm run build
npm run start
```

```bash

npx next typegen    # توليد أنواع المسارات
```

## 4) الحسابات الافتراضية (تُنشأ تلقائياً)

| الدور | اسم المستخدم | كلمة المرور |
|---|---|---|
| مدير النظام | `admin` | `Admin@12345` |
| مشرف أمني | `supervisor` | `Super@12345` |
| مستخدم | `user` | `User@12345` |

> غيّر كلمات المرور فور أول دخول من قائمة المستخدم ← «تغيير كلمة المرور».
> بيانات أولية جاهزة: 10 أصول، 46 تنبيهاً تاريخياً، 90+ قيد تدقيق، 6 ملفات مفحوصة، وسلاسل مؤشرات لآخر 60 دقيقة.

**اختبار الفحص الأمني:** ارفع ملفاً يحتوي سلسلة اختبار EICAR القياسية → سيُحظر فوراً بدرجة تهديد 100/100 ويُنشأ تنبيه حرج + رسالة في سجل التسليم.

## 8) طبقات الحماية المطبقة

1. **مدخلات**: تحقق `zod` في كل واجهة + `sanitizeText` لإزالة الوسوم والمعالجات.
2. **مصادقة**: bcrypt-12 + قفل حسابات + حد معدل + JWT موقّع + جلسات تنتهي + إعادة تحقق من حالة الحساب في كل طلب.
3. **CSRF/XSS**: كعكة `SameSite=Strict` + تحقق Origin/Referer + ترويسات `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`, `COOP`, `HSTS` في `next.config.ts` + تنزيل الملفات كـ `attachment` فقط.
4. **الملفات**: قائمة امتدادات ممنوعة، كشف النوع الحقيقي، قواعد توقيع وسلوك، إنتروبيا، حد حجم، أسماء تخزين عشوائية (منع Path Traversal)، تشفير AES-256-GCM، عزل تلقائي.
5. **الصلاحيات**: RBAC في الخادم (الحارس الموحّد `guard()`) وفي الواجهة معاً، وكل محاولة مرفوضة تُسجَّل.
6. **التدقيق**: سلسلة تجزئة + Trigger يمنع التعديل/الحذف + تصدير + تحقق سلامة.
7. **الأسرار**: كلها من `process.env` فقط — لا قيمة سرية مكتوبة في الكود.

## 9) النشر السحابي

### Docker
```bash
docker build -t deraa .
docker run -p 3000:3000 \
  -e DATABASE_URL="postgresql://user:pass@host:5432/app_db" \
  -e AUTH_SECRET="..." -e DATA_ENCRYPTION_KEY="..." deraa
```

### Vercel + Neon/Supabase
1. ارفع المشروع إلى مستودع Git.
2. أضف المتغيرات في لوحة Vercel (نفس قائمة `.env`).
3. النشر تلقائي — `next build` ثم `next start`.

### Railway / Render / Fly.io
- أمر البناء: `npm run build` • أمر التشغيل: `npm run start` • المنفذ: `3000`.
- وفّر PostgreSQL مُداراً وضع `DATABASE_URL`.

> **تنبيه أمني للنشر**: عيّن `AUTH_SECRET` و`DATA_ENCRYPTION_KEY` بقيم عشوائية قوية ولا تغيّرهما بعد الإنتاج (تغيير `DATA_ENCRYPTION_KEY` يجعل الملفات المشفّرة السابقة غير قابلة للفك). عند التشغيل بعدة نسخ، استبدل مخزن `rate-limit` في الذاكرة بـ Redis (الواجهة جاهزة لذلك دون تغيير الاستدعاءات).

## 10) التطوير اللاحق

- إضافة دور جديد أو صلاحية: عدّل `PERMISSIONS` و`ROLE_PERMISSIONS` في `src/lib/auth/rbac.ts` فقط.
- إضافة قاعدة فحص ملفات: أضف عنصراً إلى `CONTENT_RULES` في `src/lib/security/scanner.ts`.
- إضافة قاعدة فحص روابط: أضف إلى قوائم `url-scan.ts`.
- إضافة قناة تنبيه (Slack/Teams/WhatsApp): نفّذ دالة إرسال في `src/lib/notify.ts` واستدعها داخل `dispatchAlert`.
- إضافة جدول: عرّفه في `src/db/schema.ts` ثم أضف `CREATE TABLE IF NOT EXISTS` المقابل في `src/db/bootstrap.ts` وشغّل `npx drizzle-kit push`.
